# 命名即消解

English version: see `README.en.md`

“命名即消解”是一个希望陪人走过情绪混沌时刻的小页面。

很多时候，真正压垮人的不是单一的一件事，而是说不清、理不顺、也不知道该怎么表达的那团东西。这个页面想做的事情很简单：当你愿意把困境写下来，它尝试帮你把那份模糊的痛苦说得更清楚一点，命名得更准确一点。

我一直很相信一句话：叫出魔鬼名字的那一刻，魔鬼就会消解。

所以这个页面不是想替人下结论，也不是想给人标准答案，而是想提供一种更安静、更有秩序的看见方式。也许你原本只觉得“我很难受”，但当它被重新组织、被准确描述、被看见结构之后，人会比较容易从那团雾里走出来一点点。

在线体验：

- GitHub Pages: https://xiangxiangdong111-ops.github.io/nomen-dissolve/
- GitHub 仓库: https://github.com/xiangxiangdong111-ops/nomen-dissolve

这个项目想做的事：

- 给任何正在经历压力、焦虑、崩溃感、失控感的人一个可以停下来整理自己的入口。
- 用更有层次、更有语言感的方式，把难以描述的内心状态说清楚。
- 让一个公开可访问的页面，真正对陌生人也有一点点帮助，而不是只停留在“做了一个项目”。

如果你愿意，你可以把它当成一个小小的情绪整理器：

- 写下你现在卡住的事。
- 看看它怎么重新命名那份痛苦。
- 也许你不会立刻变轻松，但你可能会更明白自己正在经历什么。

我把这个页面公开放到 GitHub Pages，也把仓库开源出来，是因为我希望它不只是我本地的一次实验，而是真的能被更多人看到、用到。

如果这个页面刚好帮你把一些说不清的感受说了出来，如果它让你觉得“原来我不是乱掉了，而是我真的正在经历某种可以被理解的处境”，那我会很开心。

如果你喜欢这个项目，也欢迎去仓库点一个 Star。这会让我知道，这个页面确实有走到别人那里去。
